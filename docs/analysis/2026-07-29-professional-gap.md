# 系统对标分析 — 专业量化平台缺口

> 2026-07-29 | test-v262

## 一、已有能力 (vs 业界)

| 功能域 | 我们 | 业界标准 | 差距 |
|--------|------|---------|------|
| 因子数量 | 84 | WorldQuant 1000+ / Qlib alpha158 | **数量差距大，但 IC 质量 > 数量** |
| 因子评估 | 8 阶段 + CPCV + DSR | Alphalens + WorldQuant 准入流程 | **✅ 对齐** |
| Alpha 模型 | IC-weighted + LightGBM | Qlib DoubleEnsemble + LSTM | **弱** — 缺神经网络和多模型集成 |
| 组合优化 | 三层 + Kelly + HRP | Barra Optimizer + MSCI | **基本对齐** |
| 风险模型 | Ledoit-Wolf + 行业中性化 | Barra CNE5 + Eigenfactor | **弱** — 缺系统风险分解 |
| 执行模型 | 限价单 + 紧迫度曲线 | ITG + Kissell IS | **✅ 对齐** |
| 回测 | Walk-forward + CPCV | Qlib RollingTrainer | **基本对齐** |
| 报告 | Tear Sheet (基础) | Alphalens + Qlib Report | **弱** |
| 实时风控 | VaR + 止损 + 流动性 | Bloomberg RMS | **基本对齐** |
| 数据覆盖 | 日频 OHLCV | DolphinDB 多频 | **弱** |
| 另类数据 | 无 | WorldQuant 卫星/供应链/NLP | **无** |
| ML 可解释性 | SHAP (接口) | Qlib + Captum | **弱** — 未接入报告 |

## 二、需要加强的 (对我们 ¥5,000→¥1M 目标最关键的)

### P0 — 模型能力升级

| 功能 | 当前 | 目标 | 理由 |
|------|------|------|------|
| **模型集成** | 单一 LGB | LGB + TabNet + 简单NN 投票 | 单模型过拟合风险高，集成降低方差 |
| **滚动训练 CV** | 无 | PurgedGroupTimeSeriesSplit | 当前 train IC=0.45 可能是过拟合，需 OOS 验证 |
| **因子交互特征** | 无 | 自动生成 top-20 交互项 | LGB 能学交互但显式特征加速收敛 |

### P1 — 风险体系加固

| 功能 | 当前 | 目标 | 理由 |
|------|------|------|------|
| **Barra 风险分解** | 无 | 系统风险 vs 特质风险 + Factor Exposure | 知道亏在哪才能优化 |
| **Stress Testing** | 无 | 历史场景重放 (2015 股灾/2020 疫情) | ¥5K 账户扛不住一次黑天鹅 |
| **相关性预警** | 无 | 持仓相关性 > 0.7 告警 | 分散化幻觉 — 以为买了 5 只实际买了 1 个板块 |

### P2 — 数据与基础设施

| 功能 | 当前 | 目标 | 理由 |
|------|------|------|------|
| **财务数据 PIT** | 无 ann_date | 按公告日期严格 PIT | 当前可能用未来季报数据回测 → 前视偏差 |
| **数据质量监控** | freshness.py (基本) | 数据缺失/异常/延迟自动告警 + 仪表盘 | 数据错了全白做 |
| **实验追踪** | 无 | Git + MLflow 记录每次回测参数/结果 | 做 100 次回测后不知道哪次最好 |

## 三、暂时不需要的 (¥5K 规模不划算)

| 功能 | 理由 |
|------|------|
| 1000+ 因子 | 84 个精选因子优于 1000 个低质量因子 |
| Level-2 / Tick 数据 | 需要券商通道 + ¥50K+/年 |
| 分布式计算 | 单机够跑全 A 股 |
| Smart Order Routing | 模拟账户不需要 |
| 另类数据 | 需要购买数据源 |
| 多资产 | A 股单市场够用 |
