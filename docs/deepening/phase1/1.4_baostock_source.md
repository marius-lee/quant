# Phase 1.4 完成归档 — BaostockSource 深化

## 变更摘要
为 `BaostockSource` 补充 12 个缺失操作实现，并实现 **Akshare 自动回退机制**，实现主源 + 回退源的高可用架构。

## 新增操作

| 操作 | 主源 | 回退源 | 用途 |
|------|------|--------|------|
| `fund_flow` | — | Akshare `stock_individual_fund_flow` | 资金流因子 |
| `margin` | — | Akshare `stock_margin_detail_em` | 两融因子 |
| `lhb` | — | Akshare `stock_lhb_detail_em` | 龙虎榜因子 |
| `dividend` | — | Akshare `stock_dividend_cninfo` | 分红因子 |
| `holder_trade` | — | Akshare `stock_holder_trade_em` | 股东增减持 |
| `pledge` | — | Akshare `stock_pledge_ratio_em` | 质押因子 |
| `income` | — | Akshare `stock_profit_forecast` | 利润表 |
| `balance` | — | Akshare `stock_balance_sheet_by_report_em` | 资产负债表 |
| `cashflow` | — | Akshare `stock_cash_flow_by_report_em` | 现金流量表 |
| `daily` | Baostock | Akshare `stock_zh_a_hist` | 日线行情(自动回退) |
| `index_daily` | Baostock | Akshare `index_zh_a_hist` | 指数日线(自动回退) |
| `industry` | Baostock | Akshare `stock_board_industry_name_em` | 行业分类(自动回退) |

## 架构亮点
- **统一回退框架**: `_akshare_fallback()` 包装器统一处理回退逻辑
- **日线/指数/行业自动回退**: Baostock 失败时自动切换 Akshare
- **纯 Akshare 操作**: fund_flow/margin/lhb/dividend 等直接走 Akshare
- **统一错误处理**: 回退失败也记录错误码，不抛异常

## 代码变更
- 文件: `quant/data/sources/baostock_source.py`
- 新增行数: ~1600 行
- 核心模式: `_akshare_fallback(operation, func, *args)` 统一回退入口
- 复用现有防封禁机制 (`bs_query` + 跨进程限流 + 黑名单熔断)
