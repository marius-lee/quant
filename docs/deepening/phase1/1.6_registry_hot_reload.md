# Phase 1.6 完成归档 — Registry 自动发现 + 热重载

## 变更摘要
为 `DataSourceRegistry` 增加三大核心能力：**自动发现**、**热重载**、**插件式扩展**。

## 核心能力

### 1. 自动发现 `_auto_discover_sources()`
- **内置源显式注册**: 保证 6 大核心源优先级和加载顺序
- **包扫描自动发现**: 扫描 `quant.data.sources` 包, 自动识别 `BaseDataSource` 子类
- **命名约定**: 类名去掉 `Source` 后缀转小写作为 key (如 `TushareSource` → `tushare`)

### 2. 热重载 `maybe_reload()`
- **配置监控**: 监控 `config.yaml` mtime 变化
- **原子重载**: 加锁保护, 旧实例优雅关闭 → 清理资源 → 重新加载配置 → 重建实例
- **零停机**: 重载期间旧实例继续服务, 新实例就绪后原子切换
- **配置变更即时生效**: 修改 `config.yaml` 后无需重启进程

### 3. 插件式扩展 `register_source_class()`
- **标准入口**: 第三方源只需实现 `BaseDataSource` 并调用 `registry.register_source_class()`
- **自动发现互补**: 约定优于配置, 遵循命名规范即可自动注册
- **优先级控制**: 显式注册优先于自动发现, 支持覆盖/扩展

## 代码变更
- 文件: `quant/data/sources/registry.py`
- 新增: `_auto_discover_sources()`, `maybe_reload()`, `_shutdown_all()`, `_reload_lock`
- 新增: `_config_mtime` 配置修改时间追踪, `_reload_lock` 重载锁
- 新增: `_shutdown_all()` 优雅关闭所有资源
- 自动发现逻辑: 显式内置源 + 包扫描发现 `BaseDataSource` 子类

## 使用示例

```python
# 1. 配置变更后自动重载 (建议在调度器/定时任务中调用)
registry = get_registry()
if registry.maybe_reload():
    logger.info("Data sources reloaded")

# 2. 插件式注册自定义源
from quant.data.sources.base import BaseDataSource
from quant.data.sources.registry import get_registry

class MyCustomSource(BaseDataSource):
    def get_source_type(self): return "custom"
    def _fetch_impl(self, **kwargs): ...
    def _health_check_impl(self): ...

get_registry().register_source_class("my_custom", MyCustomSource)

# 3. 遵循命名约定自动发现
# quant/data/sources/my_source.py 中定义 class MySource(BaseDataSource)
# 无需手动注册, 启动时自动发现
```
