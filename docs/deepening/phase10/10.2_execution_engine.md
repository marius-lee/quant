### 1. 分片算法框架

```python
class SliceAlgorithmBase(ABC):
    """分片算法基类."""
    def __init__(self, config: SliceConfig): ...
    
    @abstractmethod
    def generate_slices(self, parent: ParentOrder, market_data: Dict) -> List[OrderSlice]:
        """生成分片计划."""
        pass
    
    @abstractmethod
    def on_slice_fill(self, parent: ParentOrder, slice_: OrderSlice, fill: Trade) -> List[OrderSlice]:
        """分片成交回调."""
        pass
    
    @abstractmethod
    def on_market_update(self, parent: ParentOrder, market_data: Dict) -> List[OrderSlice]:
        """行情更新回调."""
        pass
```

### 2. 五大分片算法

| 算法 | 类 | 适用场景 | 核心特点 |
|------|-----|----------|----------|
| **TWAP** | `TWAPAlgorithm` | 中小单、常规执行 | 均匀时间分片，随机化间隔/大小 |
| **VWAP** | `VWAPAlgorithm` | 大单、流动性好 | 按历史成交量分布分片 |
| **Iceberg** | `IcebergAlgorithm` | 隐藏意图、防前跑 | 显示小量，成交后自动发布下一片 |
| **POV** | `POVAlgorithm` | 参与率控制 | 按实时成交量比例动态调整 |
| **IS** | `ImplementationShortfallAlgorithm` | 紧急单、平衡冲击/机会成本 | 根据紧迫度/波动率计算最优轨迹 |

## 使用示例

```python
# 初始化引擎
engine = init_live_engine()

# 创建母单
order = ParentOrder(
    order_id=str(uuid.uuid4())[:16],
    client_order_id=str(uuid.uuid4())[:16],
    symbol="600036",
    side=OrderSide.BUY,
    total_shares=10000,
    target_price=20.50,
    order_type=OrderType.LIMIT,
    slice_config=SliceConfig(
        algorithm=SliceAlgorithm.TWAP,
        total_shares=10000,
        max_slice_size=1000,
        time_horizon_seconds=7200,  # 2小时
        randomize_slices=True,
    ),
    strategy_id="momentum_v1",
    account_id="ACC_001",
)

# 提交订单
order_id = await engine.submit_order(order)

# 监控进度
def on_update(order: ParentOrder):
    print(f"Order {order.order_id}: {order.filled_shares}/{order.total_shares} @ {order.avg_fill_price:.2f}")

engine.on_order_update = on_update

# 取消订单
engine.cancel_order(order_id)
```
