class MarginMonitor:

**核心能力**：
- 5秒间隔轮询所有连接账户的保证金率
- 四级告警：INFO(>1.5) → WARNING(1.3-1.5) → CRITICAL(1.1-1.3) → EMERGENCY(<1.1)

**核心组件**：

**核心流程**：

```python
async def check_order(self, order: ParentOrder) -> Tuple[bool, List[RiskEvent]]:
    """订单风控检查主入口"""
    # 1. 熔断器检查 - 任一熔断器开启则阻断
    for breaker in circuit_breakers:
        if not breaker.allow_request():
            return False, [RiskEvent(...)]
    
    # 2. 异常交易规则检查
    anomaly_events = await anomaly_detector.check_order(order)
    if any(e.action == BLOCK_NEW_ORDERS for e in anomaly_events):
        return False, anomaly_events
    
    # 3. 保证金检查
    if margin_ratio < 1.1:
        return False, [RiskEvent(...)]
    
    return True, []
```

**风控动作执行**：

| 动作 | 等级 | 执行逻辑 |
|------|------|----------|
| LOG_ONLY | 所有 | 仅记录警告日志 |
| BLOCK_NEW_ORDERS | WARNING/CRITICAL | 设置全局阻断标志 |
| REDUCE_POSITION | WARNING | 自动减半浮亏>10%持仓 |
| FORCE_LIQUIDATE | EMERGENCY | 1分钟内市价平掉所有持仓 |
| CIRCUIT_BREAK | EMERGENCY | 触发熔断器，记录事件 |
| ALERT | 所有 | 发送告警通知 |

### 4. 熔断器集成

复用 Phase 7 的四级熔断器架构：
- **账户级** - 保证金率<130%、单日亏损>5%、保证金使用率>90%
- **策略级** - 连续亏损≥5次、回撤>15%、胜率<35%
- **品种级** - 日内波动>8%、价差>50bps、成交量>10倍
- **全市场级** - 大盘跌幅>5%、涨跌幅比<0.2、VIX>50

**实盘集成**：
- 1秒/次检查频率
- 状态变更回调自动触发风控事件
- 熔断开启 → 立即阻断新开仓、触发减仓/强平

## 使用示例

```python
# 初始化风控系统
risk_manager = init_live_risk_manager()

# 启动风控
await risk_manager.start()

# 设置回调
def on_risk_event(event: RiskEvent):
    print(f"Risk: {event.rule_name} - {event.message}")
    if event.action == RiskAction.FORCE_LIQUIDATE:
        notify_ops_team(event)

risk_manager.on_risk_event = on_risk_event
risk_manager.on_force_liquidate = lambda acc, syms: notify_liquidation(acc, syms)

# 订单前风控检查
async def place_order(order: ParentOrder):
    allowed, events = await risk_manager.check_order(order)
    if not allowed:
        print(f"Order blocked: {[e.message for e in events]}")
        return False
    await execution_engine.submit_order(order)
    return True

# 查询风控摘要
summary = await risk_manager.get_risk_summary()
print(f"1h events: {summary['total_events_1h']}, active breakers: {summary['circuit_breakers_active']}")

# 停止风控
await risk_manager.stop()
```

## 核心数据模型

```python
@dataclass
class RiskRule:
    rule_id: str
    name: str
    level: RiskLevel
    action: RiskAction
    metric_name: str
    operator: str  # >, <, >=, <=, ==, !=
    threshold: float
    window_seconds: int = 60

@dataclass
class RiskEvent:
    event_id: str
    timestamp: datetime
    rule_id: str
    level: RiskLevel
    action: RiskAction
    strategy: str
    account: str
    symbol: Optional[str]
    metric_value: float
    threshold: float
    message: str

class RiskLevel(Enum):
    INFO, WARNING, CRITICAL, EMERGENCY

class RiskAction(Enum):
    LOG_ONLY, BLOCK_NEW_ORDERS, REDUCE_POSITION
    FORCE_LIQUIDATE, CIRCUIT_BREAK, ALERT
```
