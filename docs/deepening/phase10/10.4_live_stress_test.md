# Phase 10.4 完成归档 — 全链路实盘压测

## 变更摘要
构建全链路实盘压测框架：模拟实盘流量、并发下单、行情订阅、持仓同步、风控计算，支持多阶段负载生成、实时指标收集、自动化报告生成。

## 核心实现 (`quant/stress_test/live_stress.py`)

### 1. 压测配置 (`StressTestConfig`)

```python
@dataclass
class StressTestConfig:
    mode: StressTestMode = StressTestMode.FULL_CHAIN  # 压测模式
    duration_seconds: int = 300          # 总时长 5分钟
    target_qps: int = 10000              # 目标 QPS 1万
    ramp_up_seconds: int = 60            # 爬坡 1分钟
    steady_seconds: int = 180            # 稳态 3分钟
    spike_qps: int = 20000               # 突刺峰值 2万 QPS
    spike_duration: int = 30             # 突刺 30秒
    cooldown_seconds: int = 30           # 冷却 30秒
    
    max_concurrent_orders: int = 1000    # 最大并发下单
    max_concurrent_market_subs: int = 500
    
    symbols: List[str] = [100只股票]      # 测试品种池
    strategy_count: int = 10             # 10个并发策略
    account_count: int = 5               # 5个并发账户
    
    tick_frequency_ms: int = 100         # 行情推送 100ms
    position_sync_interval_ms: int = 1000 # 持仓同步 1秒
    risk_calc_interval_ms: int = 100      # 风控计算 100ms
```

### 2. 压测阶段 (`StressTestPhase`)

| 阶段 | 时长 | 目标 QPS | 目的 |
|------|------|----------|------|
| **WARMUP** | 12s | 1,000 | 预热连接池、JIT编译 |
| **RAMP_UP** | 60s | 10,000 | 线性爬坡到目标负载 |
| **STEADY** | 180s | 10,000 | 稳态运行，收集基准指标 |
| **SPIKE** | 30s | 20,000 | 突刺测试，验证系统极限 |
| **COOLDOWN** | 30s | 1,000 | 冷却、连接回收 |

### 3. 核心组件

#### MockBroker (模拟券商)
```python
class MockBroker(BrokerAdapterBase):
    """支持配置延迟、抖动、失败率、拒单率的模拟券商"""
    def __init__(
        self,
        config: BrokerConfig,
        base_latency_ms: float = 3.0,    # 基础延迟 3ms
        latency_jitter_ms: float = 1.5,   # 延迟抖动 ±1.5ms
        failure_rate: float = 0.001,      # 0.1% 连接失败率
        reject_rate: float = 0.005,       # 0.5% 拒单率
    ):
```
- 模拟真实网络延迟 (高斯分布)
- 支持配置失败率/拒单率，验证错误处理
- 异步模拟成交 (50-500ms 随机延迟)
- 完整的订单/成交/持仓/账户状态管理

## 使用示例

```python
# 运行默认压测
metrics = await run_stress_test()

# 自定义配置
config = StressTestConfig(
    mode=StressTestMode.FULL_CHAIN,
    target_qps=10000,
    spike_qps=20000,
    duration_seconds=300,
    strategy_count=20,
    account_count=10,
)
metrics = await run_stress_test(config)

# 获取报告
report = StressTestReport.generate(metrics, config)
print(report)

# 保存 JSON
StressTestReport.save_json(metrics, config, "stress_report.json")
```
