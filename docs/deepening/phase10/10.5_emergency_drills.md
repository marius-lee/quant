### 2. 预定义应急场景 (6大场景)

| 场景ID | 名称 | 类型 | 严重度 | RTO目标 | 核心动作 |
|--------|------|------|--------|---------|----------|
| `BROKER_FAILOVER_001` | 主券商故障自动切换备用券商 | 券商故障 | CRITICAL | 30s | 检测断连→标记不可用→切换路由→建立通道→验证下单→恢复交易 |
| `NETWORK_RECOVERY_001` | 网络中断自动重连恢复 | 网络中断 | HIGH | 60s | 检测异常→触发重连→指数退避→同步状态→补发心跳→验证通道 |
| `ORDER_CANCELLATION_001` | 错误订单紧急撤销 | 错误订单 | HIGH | 5s | 检测异常→发送撤单→确认成功→记录日志→通知风控→防复发 |
| `DATA_RECONCILIATION_001` | 持仓/资金对账不一致自动修复 | 数据不一致 | CRITICAL | 300s | 发现差异→分类分型→定位根因→自动修复→二次验证→生成报告 |
| `RISK_CIRCUIT_BREAK_001` | 风控熔断触发与恢复 | 风控触发 | CRITICAL | 60s | 触发熔断→停止开仓→执行减仓/强平→通知团队→人工复核→解除恢复 |
| `SYSTEM_OVERLOAD_001` | 系统过载自动降级 | 系统过载 | HIGH | 30s | 检测过载→降级非核心→保核心链路→触发扩容→负载恢复自动恢复 |

### 2. 演练执行引擎

```python
class EmergencyDrillManager:
    async def run_drill(
        self,
        scenario_id: str,
        dry_run: bool = False,
    ) -> DrillExecution:
        """执行演练，支持干跑/实战模式"""
```

**执行流程**：
1. 创建演练记录，状态 RUNNING
2. 顺序执行场景预期动作
3. 每步记录耗时、成功/失败、详情
4. 任一步骤失败即标记 FAILED
5. 全部成功且 RTO 达标 → PASSED
6. 生成完整执行报告

**步骤执行分类**：
| 关键词 | 执行器 | 示例 |
|--------|--------|------|
| 检测/检查/监控 | `_execute_detection_step` | 检测主券商断连 |
| 切换/路由 | `_execute_failover_step` | 切换路由到备用券商 |
| 重连/重试 | `_execute_reconnect_step` | 指数退避重试 |
| 撤销/取消 | `_execute_cancel_step` | 立即发送撤单指令 |
| 修复/修正 | `_execute_repair_step` | 自动修复差异 |
| 降级 | `_execute_degradation_step` | 降级非核心功能 |
| 强平/平仓/减仓 | `_execute_liquidation_step` | 触发强平指令 |
| 通知/告警 | `_execute_notification_step` | 通知风控团队 |
| 验证/确认 | `_execute_verification_step` | 验证备用券商下单 |
| 记录/日志/审计 | `_execute_audit_step` | 记录审计日志 |
| 恢复/解除 | `_execute_recovery_step` | 解除熔断恢复交易 |

### 3. 自动故障转移管理器 (`AutoFailoverManager`)

```python

        execution_engine: LiveOrderExecutionEngine,
        risk_manager: LiveRiskManager,
    ):
    
    def set_primary_backup(self, primary: str, backups: List[str]): ...
    def add_failover_callback(self, callback: Callable[[str, str], None]): ...
    async def start(): ...
    async def stop(): ...
```

**核心能力**：
- 5秒间隔监控主券商连接状态
- 主券商断连自动切换到备用券商
- 故障转移冷却期 (默认60秒) 防抖动
- 切换完成回调通知
- 执行引擎路由缓存自动清理
- 最大尝试次数限制 (默认3次)

**故障转移流程**：
```
检测主券商断连 (5秒间隔)
    ↓
检查备用券商可用性
    ↓
执行切换：更新主/备映射
    ↓
清空执行引擎路由缓存
    ↓
触发回调通知
    ↓
记录故障转移次数与时间
    ↓
返回成功/失败
```

### 4. 数据对账引擎 (`ReconciliationEngine`)

```python
class ReconciliationEngine:
    """定时/实时对账、差异检测、自动修复"""
    
    def __init__(
        self,
        broker_manager: BrokerManager,
        execution_engine: LiveOrderExecutionEngine,
    ):
    
    async def start(): ...
    async def stop(): ...
    async def reconcile_all() -> Dict: ...
    async def resolve_delta(delta: Dict) -> bool: ...
```

**对账配置**：
| 参数 | 默认值 | 说明 |
|------|--------|------|
| `check_interval` | 300s | 对账间隔 5分钟 |
| `position_tolerance` | 1% | 持仓容差 |
| `cash_tolerance` | 10000 | 资金容差 1万 |
| `trade_tolerance` | 0 | 成交数零容差 |

**对账流程**：
```
定时触发 (5分钟/次)
    ↓
遍历所有连接券商
    ↓
查询券商持仓/资金/成交
    ↓
对比本地数据
    ↓
差异分类：持仓/资金/成交数
    ↓
差异超阈值 → 记录差异 → 触发回调
    ↓
自动修复或人工介入
    ↓
修复后二次验证
```

**差异分类**：
| 类型 | 容差 | 处理 |
|------|------|------|
| 持仓差异 | >1% | 自动修复/告警 |
| 资金差异 | >1万 | 告警/人工 |
| 成交数差异 | 0 | 立即告警/冻结 |

## 使用示例

```python
# 初始化应急管理器
drill_manager = init_emergency_drill_manager()

# 注册自定义场景
custom_scenario = EmergencyScenario(
    scenario_id="CUSTOM_001",
    name="自定义场景",
    description="...",
    emergency_type=EmergencyType.MARKET_ANOMALY,
    severity=DrillSeverity.HIGH,
    expected_actions=["步骤1", "步骤2"],
    expected_rto_seconds=60,
    success_criteria={"custom_metric": {"max": 100}},
)
drill_manager.add_scenario(custom_scenario)

# 执行演练 (干跑模式)
drill = await drill_manager.run_drill("BROKER_FAILOVER_001", dry_run=True)
print(f"Drill result: {'PASSED' if drill.success else 'FAILED'}")
print(f"RTO: {drill.actual_rto_seconds:.1f}s")

# 执行实战演练
drill = await drill_manager.run_drill("NETWORK_RECOVERY_001", dry_run=False)

# 查看历史
history = await drill_manager.get_drill_history(limit=10)
stats = drill_manager.get_drill_stats()

# 启用自动故障转移
failover = init_auto_failover_manager()
failover.set_primary_backup("broker_primary", ["broker_backup1", "broker_backup2"])
failover.add_failover_callback(lambda from_b, to_b: alert_ops(f"Failover: {from_b} -> {to_b}"))
await failover.start()

# 启动对账引擎
reconcile = init_reconciliation_engine()
reconcile.on_delta_detected = lambda d: alert_ops(f"Delta detected: {d}")
reconcile.on_delta_resolved = lambda d: logger.info(f"Delta resolved: {d}")
await reconcile.start()

# 手动触发对账
result = await reconcile.reconcile_all()
print(f"Checked {result['accounts_checked']} accounts, found {result['deltas_found']} deltas")
```
