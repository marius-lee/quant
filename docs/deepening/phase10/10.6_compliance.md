## 核心实现 (`quant/compliance/compliance.py`)

### 1. 客户适当性管理 (`ClientSuitabilityManager`)

```python
class ClientSuitabilityManager:
    """客户适当性管理器 - 依据《证券期货投资者适当性管理办法》"""
    
    async def check_suitability(
        self,
        client_id: str,
        product_code: str,
        investment_amount: float = 0.0,
    ) -> SuitabilityCheckResult:
        """执行适当性检查"""
```

**核心能力**：
- 客户画像管理：风险等级(C1-C4)、资质、资产、经验
- 产品风险等级：R1-R5 五级分类
- 适当性检查：风险等级匹配、资质匹配、最低投资额、黑名单
- 专业/合格投资者识别 (R4/R5 产品)
- 检查历史完整记录

**风险等级映射**：
| 客户等级 | 可购买产品 |
|----------|------------|
| C1 稳健型 | R1 |
| C2 谨慎型 | R1-R2 |
| C3 平衡型 | R1-R3 |
| C4 进取型 | R1-R4 |
| C5 激进型 | R1-R5 |

**检查维度**：
1. 风险等级匹配 (客户风险 >= 产品风险)
2. 最低投资额检查
3. 专业/合格投资者资质 (R4/R5 产品)
4. 黑名单/限制名单检查
5. 客户状态检查 (active/blacklisted)

### 2. 穿透式监管报送引擎 (`RegulatoryReportingEngine`)

```python
class RegulatoryReportingEngine:
    """穿透式监管报送 - 7大类报告自动生成"""
```

**报送类型与频次**：

| 报告类型 | 代码 | 频次/时间 | 内容 |
|----------|------|-----------|------|
| 每日交易汇总 | `DAILY_TRADE` | 交易日 18:00 | 成交笔数/量/额、买卖分布 |
| 持仓快照 | `POSITION_SNAPSHOT` | 收盘后 16:00 | 全量持仓、盈亏、市值 |
| 资金流水 | `FUND_FLOW` | 交易日 18:00 | 总资产、可用/冻结资金、保证金率 |
| 大额交易报备 | `LARGE_TRADE` | 每 30 分钟 | 单笔 ≥1000万交易详情 |
| 异常交易报备 | `ABNORMAL_TRADE` | 每 15 分钟 | 价格偏离>9%、量能异常 |
| 风控指标 | `RISK_INDICATOR` | 交易日 18:00 | 保证金率、集中度、敞口、盈亏 |
| 月度汇总 | `MONTHLY_SUMMARY` | 每月 1 号 9:00 | 月度综合报告 |

**大额/异常阈值**：
| 阈值类型 | 默认值 | 说明 |
|----------|--------|------|
| 大额交易 | 1000万 | 单笔成交额 |
| 价格偏离 | 9% | 涨跌停附近 |
| 量能异常 | 5倍 | 平均成交量倍数 |

**报告流程**：
```
定时触发 (cron调度)
    ↓
收集多券商数据
    ↓
生成 JSON 报告文件
    ↓
计算 SHA256 哈希 (防篡改)
    ↓
存储报告记录
    ↓
可选：提交监管平台 (模拟)
```

### 4. 审计追踪系统 (`AuditTrail`)

```python
class AuditTrail:
    """不可篡改的操作审计日志 - 哈希链完整性校验"""
```

**核心特性**：
- **日志分级**：info/warning/critical
- **事件分类**：trade/order/risk/compliance/system/admin
- **操作人分类**：user/system/api
- **日志轮转**：按天分文件 (audit_YYYYMMDD.jsonl)
- **缓冲刷新**：1秒间隔批量写入
- **完整性校验**：SHA256 哈希链验证

**日志字段**：
```json
{
  "log_id": "AUDIT_20240115_103000_abc12345",
  "timestamp": "2024-01-15T10:30:00Z",
  "event_type": "trade",
  "operator": "strategy_momentum",
  "operator_type": "api",
  "action": "place_order",
  "resource_type": "order",
  "resource_id": "ORDER_123",
  "before": {},
  "after": {"symbol": "600036", "side": "buy", "qty": 100},
  "ip_address": "10.0.0.1",
  "result": "success",
  "severity": "info"
}
```

**完整性校验**：
- 哈希链：当前行哈希 = SHA256(前一行哈希 + 当前行内容)
- 首行前哈希 = 64个0
- 逐行验证，发现篡改立即报警

## 使用示例

```python
# 初始化合规管理器
compliance = init_compliance_manager()

# 启动合规系统
await compliance.start()

# 注册客户
client = ClientProfile(
    client_id="CLIENT_001",
    name="张三",
    risk_level=ClientRiskLevel.MODERATE,
    is_qualified_investor=True,
    financial_assets=5000000,
)
compliance.suitability.register_client(client)

# 注册产品
product = ProductInfo(
    product_code="PROD_001",
    name="激进型量化基金",
    risk_level=ProductRiskLevel.R5,
    min_investment=100000,
)
compliance.suitability.register_product(product)

# 下单前合规检查
order = ParentOrder(symbol="600036", side=OrderSide.BUY, ...)
allowed, violations = await compliance.check_order_compliance(order, "CLIENT_001")
if not allowed:
    print(f"合规拦截: {violations}")

# 适当性检查
result = await compliance.suitability.check_suitability(
    "CLIENT_001", "PROD_001", 200000
)
print(f"适当性: {'通过' if result.passed else '拦截'} - {result.reason}")

# 生成监管报告
report = await compliance.reporting.generate_report(
    ReportType.DAILY_TRADE, date.today()
)

# 审计日志
await compliance.audit_trail.log_event(
    event_type="trade",
    operator="strategy_momentum",
    operator_type="api",
    action="place_order",
    resource_type="order",
    resource_id="ORDER_123",
    before={},
    after={"symbol": "600036", "side": "buy", "qty": 100},
)

# 资金账户同步
await compliance.fund_accounts.sync_all()

# 获取合规状态
status = await compliance.get_compliance_status()
```
