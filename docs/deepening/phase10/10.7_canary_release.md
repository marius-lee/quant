## 核心实现 (`quant/canary/canary.py`)

### 1. 灰度发布管理器 (`CanaryReleaseManager`)

```python
class CanaryReleaseManager:
    """灰度发布管理器 - 全生命周期管理"""
    
    def create_canary(self, config: CanaryConfig) -> str:
        """创建灰度发布配置"""
    
    async def start_canary(self, canary_id: str) -> bool:
        """启动灰度发布"""
    
    async def pause_canary(self, canary_id: str) -> bool:
        """暂停灰度发布"""
    
    async def resume_canary(self, canary_id: str) -> bool:
        """恢复灰度发布"""
    
    async def rollback_canary(self, canary_id: str, trigger: RollbackTrigger = RollbackTrigger.MANUAL) -> bool:
        """回滚灰度发布"""
    
    async def complete_canary(self, canary_id: str) -> bool:
        """完成灰度发布 (全量发布)"""
```

**核心能力**：
- 生命周期管理：PLANNING → PREPARING → RUNNING → PAUSED/ROLLING_BACK/COMPLETED/FAILED
- 多阶段渐进式流量分发
- 实时指标采集与监控
- 自动/手动回滚触发
- A/B 测试对比分析

### 2. 灰度配置 (`CanaryConfig`)

```python
@dataclass
class CanaryConfig:
    canary_id: str
    name: str
    strategy_ids: List[str]           # 灰度策略
    account_ids: List[str]            # 灰度账户
    symbol_filter: List[str]          # 品种过滤
    
    traffic_split: float = 0.01       # 初始流量 1%
    split_strategy: TrafficSplitStrategy = TrafficSplitStrategy.PERCENTAGE
    
    phases: List[Dict] = [            # 6阶段渐进式发布
        {"traffic_split": 0.01, "duration_hours": 1},   # 1%
        {"traffic_split": 0.05, "duration_hours": 2},   # 5%
        {"traffic_split": 0.10, "duration_hours": 4},   # 10%
        {"traffic_split": 0.25, "duration_hours": 8},   # 25%
        {"traffic_split": 0.50, "duration_hours": 12},  # 50%
        {"traffic_split": 1.00, "duration_hours": 0},   # 100%
    ]
    
    rollback_rules: List[Dict] = [    # 自动回滚规则
        {"trigger": "pnl_drawdown", "threshold": -0.05},
        {"trigger": "sharpe_degradation", "threshold": -0.5},
        {"trigger": "win_rate_drop", "threshold": -0.15},
        {"trigger": "error_rate_spike", "threshold": 0.05},
        {"trigger": "circuit_breaker", "threshold": 1},
    ]
    
    enable_ab_test: bool = True
    control_group_ratio: float = 0.5
    max_duration_hours: float = 24.0
```

**默认发布阶段**：
| 阶段 | 流量比例 | 持续时间 | 目的 |
|------|----------|----------|------|
| Phase 1 | 1% | 1小时 | 冷启动验证 |
| Phase 2 | 5% | 2小时 | 小流量验证 |
| Phase 3 | 10% | 4小时 | 中流量验证 |
| Phase 4 | 25% | 8小时 | 中大流量验证 |
| Phase 5 | 50% | 12小时 | 大流量验证 |
| Phase 6 | 100% | 无限制 | 全量发布 |

### 3. 回滚触发机制

```python
class RollbackTrigger(Enum):
    MANUAL = "manual"                    # 手动触发
    PNL_DRAWDOWN = "pnl_drawdown"        # 回撤超阈值
    SHARPE_DEGRADATION = "sharpe_degradation"  # 夏普比恶化
    WIN_RATE_DROP = "win_rate_drop"      # 胜率下降
    VOLATILITY_SPIKE = "volatility_spike"  # 波动率飙升
    ERROR_RATE_SPIKE = "error_rate_spike"  # 错误率飙升
    CIRCUIT_BREAKER = "circuit_breaker"  # 熔断器触发
    CUSTOM_METRIC = "custom_metric"      # 自定义指标
```

**默认回滚规则**：
| 触发条件 | 阈值 | 响应 |
|----------|------|------|
| 单日回撤 | >5% | 立即回滚 |
| 夏普比下降 | >0.5 | 立即回滚 |
| 胜率下降 | >15% | 立即回滚 |
| 错误率飙升 | >5% | 立即回滚 |
| 熔断器触发 | 任意 | 立即回滚 |

**回滚流程**：
```
触发条件检测 (10秒/次)
    ↓
状态标记: ROLLING_BACK
    ↓
流量切回 0% (切回对照组)
    ↓
撤销灰度组未完成订单
    ↓
记录回滚事件 (触发器/阈值/时刻/阶段)
    ↓
状态标记: COMPLETED
    ↓
触发回调通知
```

## 使用示例

```python
# 初始化灰度管理器
canary_manager = init_canary_manager()

# 创建灰度配置
config = CanaryConfig(
    canary_id="momentum_v2_canary_001",
    name="动量策略v2灰度发布",
    strategy_ids=["momentum_v2"],
    account_ids=["ACC_001", "ACC_002"],
    traffic_split=0.01,
    phases=[
        {"traffic_split": 0.01, "duration_hours": 1, "name": "cold_start"},
        {"traffic_split": 0.05, "duration_hours": 2, "name": "small_scale"},
        {"traffic_split": 0.10, "duration_hours": 4, "name": "medium_scale"},
        {"traffic_split": 0.25, "duration_hours": 8, "name": "large_scale"},
        {"traffic_split": 0.50, "duration_hours": 12, "name": "half_release"},
        {"traffic_split": 1.00, "duration_hours": 0, "name": "full_release"},
    ],
    rollback_rules=[
        {"trigger": "pnl_drawdown", "threshold": -0.03, "description": "回撤3%回滚"},
        {"trigger": "sharpe_degradation", "threshold": -0.3, "description": "夏普比下降0.3"},
    ],
)
canary_id = canary_manager.create_canary(config)

# 启动灰度
await canary_manager.start_canary(canary_id)

# 实时监控
dashboard = get_canary_dashboard()
overview = dashboard.get_overview()
detail = dashboard.get_canary_detail(canary_id)

# 图表数据
chart_data = dashboard.get_metrics_chart_data(canary_id, "sharpe_ratio", "canary")

# A/B 测试对比
ab_results = dashboard.get_ab_test_results(canary_id)

# 手动控制
await canary_manager.pause_canary(canary_id)      # 暂停
await canary_manager.resume_canary(canary_id)     # 恢复
await canary_manager.rollback_canary(canary_id)   # 手动回滚
await canary_manager.complete_canary(canary_id)   # 全量发布
```
