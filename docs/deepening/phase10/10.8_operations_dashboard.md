**核心能力**：

### 3. REST API (`DashboardAPI`)

```python
class DashboardAPI:
    async def get_overview(self) -> Dict:           # 总览聚合
```

## 核心指标体系

### PnL 分析
| 指标 | 来源 | 刷新 |
|------|------|------|
| 总盈亏 | 多账户聚合 | 2秒 |
| 日盈亏 | T+0 实时 | 2秒 |
| 未实现盈亏 | 持仓市值 - 成本 | 2秒 |
| 已实现盈亏 | 成交记录累计 | 2秒 |
| 累计盈亏 | 总盈亏累计 | 2秒 |
| 总资产 | 多账户聚合 | 2秒 |
| 现金/持仓市值 | 资金/持仓拆分 | 2秒 |

### 持仓分析
| 维度 | 指标 |
|------|------|
| 单品种 | 数量/均价/市价/市值/盈亏/权重/板块/策略/账户 |
| 分策略聚合 | 策略级持仓汇总 |
| 分账户聚合 | 账户级持仓汇总 |
| 板块分布 | 行业/板块分布热力图 |

### 成交质量
| 指标 | 目标 | 采集 |
|------|------|------|
| 平均滑点 | <5bps | 实时计算 |
| 最大滑点 | 监控异常 | 实时 |
| 滑点分布 | 区间统计 | 实时 |
| 成交率 | >99% | 实时 |
| 部分成交率 | <5% | 实时 |
| 拒单率 | <1% | 实时 |
| P50 延迟 | <5ms | 实时 |
| P99 延迟 | <50ms | 实时 |

### 风控指标
| 维度 | 指标 | 告警阈值 |
|------|------|----------|
| 保证金 | 比率/已用/可用 | <1.3 告警 |
| 敞口 | 总/多/空/净 | 监控 |
| 集中度 | 单一/前5/前10/HHI | >30%/50%/70% 告警 |
| 希腊值 | Delta/Gamma/Vega/Theta | 监控 |
| VaR/ES | 95%/99% | 监控 |
| 回撤 | 最大/当前 | >5%/3% 告警 |
| 熔断器 | 活跃数/详情 | 任意开启即告警 |

### 合规状态
| 维度 | 指标 | 告警 |
|------|------|------|
| 适当性 | 24h检查数/通过率 | 失败即告警 |
| 报送 | 24h生成/提交/失败 | 失败即告警 |
| 资金账户 | 总数/活跃/冻结/同步失败 | 异常即告警 |
| 审计 | 1h日志/错误/完整性 | 错误即告警 |
| 违规 | 24h违规数/详情 | 任意即告警 |

### 系统监控
| 指标 | 告警阈值 |
|------|----------|
| CPU | >80% |
| 内存 | >85% |
| 磁盘 | >90% |
| 网络/磁盘IO | 监控趋势 |
| 进程/线程/FD | 监控泄漏 |
| 数据库连接/延迟/连接池 | >80% 告警 |
| 消息队列深度/吞吐 | 积压告警 |
