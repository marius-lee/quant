# Phase 2.4 完成归档 — 资源依赖注入

## 变更摘要
为所有 Dagster 资源添加多环境支持 (Dev/Staging/Prod)，通过 `EnvVar` 实现配置注入，支持 Dev/Staging/Prod 隔离配置。

## 核心变更

### 1. 统一资源基类模式
| 资源 | 配置参数 | 环境变量注入 |
|------|----------|--------------|
| `DataSourceRegistryResource` | `state_dir`, `state_dir_env` | `QUANT_STATE_DIR` |
| `FactorStoreResource` | `db_path`, `db_path_env` | `QUANT_FACTOR_DB_PATH` |
| `TradeRepoResource` | `db_path`, `db_path_env` | `QUANT_TRADE_DB_PATH` |
| `MarketDBResource` | `db_path`, `db_path_env` | `QUANT_MARKET_DB_PATH` |

### 2. 实现模式
```python
class TradeRepoResource(dg.ConfigurableResource):
    db_path: str = "quant/data/trades.db"
    db_path_env: Optional[str] = None

    def __post_init__(self):
        if self.db_path_env:
            self.db_path = EnvVar(self.db_path_env).get_value()

    def get_client(self):
        from quant.data.repos import TradeRepo
        return TradeRepo(db_path=self.db_path)
```

### 3. 使用方式
```yaml
# config.yaml (通过 EnvVar 注入)
resources:
  trade_repo:
    config:
      db_path_env: "QUANT_TRADE_DB_PATH"
```

```bash
# 环境变量设置
export QUANT_TRADE_DB_PATH="/data/prod/trades.db"
```
