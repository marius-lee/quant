# Phase 2.5 完成归档 — Run 级重试策略

## 变更摘要
为 Dagster Jobs 添加 `RetryPolicy`，实现任务级重试策略：瞬时失败自动恢复，永久失败快速失败。

## 核心配置

### 1. 日线交易作业 (`daily_trading_job`)
```python
RETRY_POLICY = RetryPolicy(
    max_retries=3,
    delay=10,        # 10秒基础延迟
    backoff=2.0,     # 指数退避倍数
    jitter=0.1,      # 10% 抖动防雷群效应
    retry_on_asset_failure=True,  # Asset 失败时重试
)
```

### 2. 周度评估作业 (`weekly_evaluation_job`)
```python
RetryPolicy(
    max_retries=2,      # 周度评估重试少一点
    delay=60,           # 1分钟基础延迟 (任务耗时较长)
    backoff=2.0,
    jitter=0.1,
    retry_on_asset_failure=True,
)
```

## 重试策略设计

| 场景 | 行为 | 配置依据 |
|------|------|----------|
| 网络抖动/数据源暂时不可用 | 自动重试 (指数退避) | `delay=10, backoff=2.0` |
| 数据源配额耗尽/权限错误 | 快速失败不重试 | 由 `DataSourceErrorCode.is_fatal()` 控制 |
| 因子计算 OOM/超时 | 重试 3 次 | `max_retries=3` |
| 周度评估超时 | 重试 2 次 | `max_retries=2` (耗时长) |

## 退避时间线 (Daily Job)
| 重试次数 | 延迟时间 | 累计时间 |
|----------|----------|----------|
| 第 1 次 | 10s ± 1s | 10s |
| 第 2 次 | 20s ± 2s | 30s |
| 第 3 次 | 40s ± 4s | 70s |
| 总计 | - | ~70秒 |
