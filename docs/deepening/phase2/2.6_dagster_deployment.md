# Phase 2.6 完成归档 — Dagster UI 部署

## 变更摘要
完成 Dagster 生产级部署方案：Dockerfile 多阶段构建、Docker Compose 编排、启动脚本、环境变量管理。

## 交付物

### 1. Dockerfile 多阶段构建 (`Dockerfile.dagster`)
- **Builder Stage**: 编译依赖、构建轮子、安装项目包
- **Runtime Stage**: 仅包含运行时依赖、非 root 用户、健康检查
- **优化**: 预编译轮子缓存、非 root 用户、最小化镜像体积

### 2. Docker Compose 编排 (`docker-compose.dagster.yml`)
| 服务 | 端口 | 资源限制 | 说明 |
|------|------|----------|------|
| `postgres` | 5432 | 1G mem | Dagster 存储后端 |
| `dagster-daemon` | - | 2G mem | 调度守护进程 |
| `dagster-webserver` | 3000 | 1G mem | Web UI |

### 3. 环境变量管理 (`.env.dagster.example`)
| 类别 | 变量 | 示例 |
|------|------|------|
| PostgreSQL | `POSTGRES_PASSWORD` | `dagster` |
| Quant Paths | `QUANT_STATE_DIR`, `QUANT_FACTOR_DB_PATH` | `/data/prod/...` |
| API Tokens | `TUSHARE_TOKEN`, `TICKFLOW_API_KEY` | 密文注入 |

### 4. 启动脚本 (`scripts/start_dagster.sh`)
```bash
# 开发模式
./scripts/start_dagster.sh start dev

# 生产模式
./scripts/start_dagster.sh start prod

# 常用命令
./scripts/start_dagster.sh logs          # 查看日志
./scripts/start_dagster.sh stop          # 停止
./scripts/start_dagster.sh restart       # 重启
./scripts/start_dagster.sh clean         # 清理数据
```
