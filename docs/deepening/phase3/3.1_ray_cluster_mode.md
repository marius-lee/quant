# Phase 3.1 完成归档 — Ray Cluster Mode Enhancements

## 变更摘要
增强 `quant/factor/distributed/ray_config.py`，支持 KubeRay CRD、Actor 池、内存压力监控、自动分区策略选择。

## 核心增强

### 1. RayConfig 增强
| 新增字段 | 类型 | 默认值 | 说明 |
|----------|------|--------|------|
| `kuberay_namespace` | str | "ray-system" | KubeRay 命名空间 |
| `kubeconfig` | Optional[str] | None | 自定义 kubeconfig 路径 |
| `actor_pool_size` | int | 0 | Actor 池大小 (0=禁用) |
| `actor_idle_timeout` | int | 300 | Actor 空闲超时(秒) |

### 2. KubeRay CRD 支持
- **模式扩展**: `mode: "k8s"` 支持 KubeRay Operator
- **自动地址解析**: `ray://ray-head.{namespace}.svc:10001`
- **自定义 kubeconfig**: 支持多集群环境
- **命名空间隔离**: 支持多租户 Ray 集群

### 3. Actor 池
| 类/函数 | 功能 |
|---------|------|
| `FactorStoreActorPool` | FactorStore Actor 池，复用 DB 连接 |
| `acquire()/release()` | 获取/释放 Actor |
| `health_check()` | 健康检查 + 空闲 Actor 自动清理 |
| `get_actor_pool()` | 全局 Actor 池单例 |

### 4. 内存压力监控
| 组件 | 功能 |
|------|------|
| `MemoryPressureMonitor` | 后台线程监控内存 |
| `object_store_threshold` | Ray 对象存储阈值 (默认 85%) |
| `system_memory_threshold` | 系统内存阈值 (默认 85%) |
| `check_interval` | 检查间隔 (默认 10s) |
| 自动 GC | 超阈值触发 `gc.collect()` |

### 5. 自动分区策略选择
```python
auto_select_partition_strategy(
    num_factors: int,      # 因子数
    num_symbols: int,      # 股票数
    num_dates: int,        # 交易日数
    cluster_cpus: int      # 集群 CPU 核心数
) -> (strategy_name, partition_kwargs)
```

| 规模 | 条件 | 策略 | 参数 |
|------|------|------|------|
| 小规模 | total_work < 50k, cpus ≤ 8 | `date` | max_partition_size=50k |
| 中等 | total_work < 500k | `composite` | dates=5, factors=20 |
| 大规模 | factors > 50 | `factor` | factors_per_partition |
