# Phase 3.2 完成归档 — Actor Pool Integration

## 变更摘要
将 `FactorStoreActorPool` 集成到 `DistributedFactorEngine`，实现 DB 连接复用，避免每个 Ray Task 重复初始化 FactorStore。

## 核心变更

### 1. 引擎参数扩展
| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `use_actor_pool` | bool | False | 启用 Actor 池模式 |
| `actor_pool_size` | int | 0 | Actor 池大小 (0=自动计算) |

### 2. Actor Pool 架构
```
DistributedFactorEngine
    └── _actor_pool: FactorStoreActorPool
            ├── _actors: List[ActorHandle]      # 所有 Actor
            ├── _available: List[ActorHandle]   # 可用 Actor 队列
            ├── _in_use: Set[ActorHandle]       # 正在使用的 Actor
            └── _last_used: Dict[Actor, float]  # 最后使用时间
```

### 3. Actor 生命周期
```
acquire() → materialize() → release() → health_check() → cleanup idle
    ↓           ↓              ↓              ↓           ↓
  获取Actor   执行物化      归还池中    健康检查+清理  超时自动回收
```

### 4. Actor 实现细节
```python
@ray.remote(num_cpus=0, resources={"factor_compute": 0.01})
class FactorStoreActor:
    def __init__(self, config):
        self.store = FactorStore(**config)
        self.last_used = time.time()
    
    def materialize(self, dates, factors, symbols, force=False):
        self.last_used = time.time()
        return self.store.materialize(dates, factors, symbols, force)
    
    def health_check(self):
        return {"status": "healthy", "last_used": self.last_used}
    
    def close(self):
        self.store.close()
```

### 5. 引擎集成
```python
# 引擎初始化新参数
engine = DistributedFactorEngine(
    ...
    use_actor_pool=True,
    actor_pool_size=4,  # 0=自动计算
)

# prepare() 自动初始化 Actor 池
def prepare(self):
    ...
    if self.use_actor_pool and ray.is_initialized():
        pool_size = self.actor_pool_size or max(1, len(self._partitions) // 2)
        self._actor_pool = get_actor_pool(
            pool_size=pool_size,
            factor_store_config={"db_path": "quant/data/factor_cache.db"},
        )

# _submit_tasks() 自动选择执行模式
if self.use_actor_pool and self._actor_pool:
    # Actor 模式: 从池获取 Actor 执行
    @ray.remote
    def compute_partition_with_actor(partition, actor_pool_ref):
        actor = ray.get(actor_pool_ref.acquire.remote())
        try:
            result = ray.get(actor.materialize.remote(...))
        finally:
            actor_pool_ref.release.remote(actor)
```
