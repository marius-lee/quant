# Phase 3.3 完成归档 — 自动分区策略选择

## 变更摘要
集成 `auto_select_partition_strategy()` 到 `DistributedFactorEngine`，实现基于工作负载的自动分区策略选择。

## 核心逻辑

### 自动选择算法
```python
def auto_select_partition_strategy(
    num_factors: int,      # 因子数量
    num_symbols: int,      # 股票数量
    num_dates: int,        # 交易日数
    cluster_cpus: int      # 集群 CPU 核心数
) -> tuple[str, dict]:
    total_work = num_factors * num_symbols * num_dates
    
    # 小规模: 单机足够，按日期分区即可
    if total_work < 50000 and cluster_cpus <= 8:
        return "date", {"max_partition_size": 50000}
    
    # 中等规模: 日期 × 因子 组合
    if total_work < 500000:
        return "composite", {
            "max_partition_size": 50000,
            "dates_per_partition": 5,
            "factors_per_partition": 20,
        }
    
    # 大规模: 因子并行为主
    if num_factors > 50:
        return "factor", {"factors_per_partition": max(10, num_factors // cluster_cpus)}
    
    # 默认组合策略
    return "composite", {...}
```

### 决策矩阵
| 规模 | 条件 | 策略 | 核心参数 |
|------|------|------|----------|
| 小规模 | total_work < 50k, cpus ≤ 8 | `date` | max_partition_size=50k |
| 中等 | total_work < 500k | `composite` | dates=5, factors=20 |
| 大规模 | factors > 50 | `factor` | factors_per_partition |
