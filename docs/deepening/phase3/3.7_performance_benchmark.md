# Phase 3.7 完成归档 — 性能基准测试

## 变更摘要
创建基准测试脚本 `scripts/benchmark_factorization.py`，支持多模式性能测试，自动生成基准报告。

## 基准测试脚本

### 脚本功能
```bash
# 完整基准测试 (全量物化 + 分布式 + 增量 + 单日)
python scripts/benchmark_factorization.py --mode all --actors 8 --cpus 32

# 单独模式
python scripts/benchmark_factorization.py --mode full --actors 8 --cpus 32      # 全量物化
python scripts/benchmark_factorization.py --mode incremental --actors 4 --cpus 16   # 增量物化
python scripts/benchmark_factorization.py --mode distributed --actors 16 --cpus 64  # 分布式
python scripts/benchmark_factorization.py --mode single_date --cpus 8          # 单日物化
```

### 测试模式配置

| 模式 | 日期范围 | 分区策略 | Actor池 | 用途 |
|------|----------|----------|---------|------|
| `full` | 2020-2024 | composite | 关闭 | 全量回测基准 |
| `incremental` | 最近30天 | date | 关闭 | 日增量验证 |
| `distributed` | 2023-2024 | composite | 开启(8 actors) | 分布式性能 |
| `single_date` | 单日 | date | 关闭 | 单日延迟基准 |

### 基准指标
```python
@dataclass
class BenchmarkResult:
    mode: str                    # 测试模式
    start_date: str              # 起始日期
    end_date: str                # 结束日期
    num_factors: int             # 因子数
    num_symbols: int             # 股票数
    num_dates: int               # 交易日数
    total_work_units: int        # 总工作量
    duration_seconds: float      # 耗时(秒)
    rows_written: int            # 写入行数
    partitions: int              # 分区数
    actor_pool_used: bool        # 是否用Actor池
    actor_pool_size: int         # Actor池大小
    incremental: bool            # 是否增量
    memory_peak_mb: float        # 内存峰值(MB)
    timestamp: str               # 时间戳
```

## 基准测试脚本

### `scripts/benchmark_factorization.py`
- 支持 `--mode` (full/incremental/distributed/single_date/all)
- 支持 `--actors N` Actor池大小
- 支持 `--cpus N` Ray CPU核心数
- 支持 `--output file.json` 结果输出
- 自动计算吞吐率、内存峰值、延迟

### 运行示例
```bash
# 完整基准测试
python scripts/benchmark_factorization.py --mode all --actors 8 --cpus 32 --output benchmark_20241220.json

# 仅分布式模式
python scripts/benchmark_factorization.py --mode distributed --actors 16 --cpus 64

# 仅增量模式
python scripts/benchmark_factorization.py --mode incremental --actors 4 --cpus 16
```
