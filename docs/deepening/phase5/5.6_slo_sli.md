## 核心概念

### SLI (Service Level Indicator) - 服务级别指标
| SLI 名称 | 定义 | 计算方式 | 目标值 |
|----------|------|----------|--------|
| 可用性 | 成功请求 / 总请求 | `sum(rate(http_requests_total{status=~"2.."}[5m])) / sum(rate(http_requests_total[5m]))` | ≥ 99.9% |
| 延迟 P99 | P99 延迟 | `histogram_quantile(0.99, rate(http_request_duration_seconds_bucket[5m]))` | < 500ms |
| 吞吐可用性 | 成功吞吐 / 总吞吐 | `sum(rate(trades_total{status="success"}[5m])) / sum(rate(trades_total[5m]))` | ≥ 99.5% |
| 数据新鲜度 | 最新数据年龄 | `time() - max(data_timestamp)` | < 5min |
| 同步成功率 | 同步成功 / 总同步 | `sum(rate(cdc_sync_success[5m])) / sum(rate(cdc_sync_total[5m]))` | ≥ 99.9% |

### Error Budget & Burn Rate 告警
```python
# quant/monitoring/slo.py
from dataclasses import dataclass
from typing import Dict, List

@dataclass
class ErrorBudget:
    slo_name: str
    total_budget: float      # 总错误预算 (1 - SLO target)
    consumed_budget: float   # 已消耗预算
    remaining_budget: float  # 剩余预算
    burn_rate: float         # 燃烧率 (消耗速度)
    time_to_exhaust: float   # 预计耗尽时间 (小时)
    status: SLOStatus

def calculate_error_budget(slo: SLODefinition, current_sli: float) -> ErrorBudget:
    """计算错误预算."""
    total_budget = 1 - slo.target
    consumed = 1 - current_sli
    remaining = max(0, total_budget - consumed)
    
    # 计算燃烧率 (过去 1h 消耗速度)
    # 简化: 假设线性消耗
    burn_rate = consumed / (1 if total_budget > 0 else 1)
    time_to_exhaust = remaining / burn_rate if burn_rate > 0 else float('inf')
    
    if remaining <= 0:
        status = SLOStatus.BREACHED
    elif remaining / total_budget < 0.1:
        status = SLOStatus.AT_RISK
    else:
        status = SLOStatus.MET
    
    return ErrorBudget(
        slo_name=slo.name,
        total_budget=total_budget,
        consumed_budget=consumed,
        remaining_budget=remaining,
        burn_rate=burn_rate,
        time_to_exhaust=time_to_exhaust,
        status=status,
    )

def check_burn_rate_alerts(slo: SLODefinition, window_1h: float, window_6h: float, window_24h: float) -> List[Dict]:
    """基于 Burn Rate 的多窗口告警 (Google SRE 实践)."""
    alerts = []
    target = slo.target
    
    # 1h 窗口: burn rate > 14.4x (1% budget in 1h)
    if window_1h > target * 14.4:
        alerts.append({"severity": "critical", "window": "1h", "burn_rate": window_1h / target})
    
    # 6h 窗口: burn rate > 6x (5% budget in 6h)
    if window_6h > target * 6:
        alerts.append({"severity": "critical", "window": "6h", "burn_rate": window_6h / target})
    
    # 24h 窗口: burn rate > 1.5x (10% budget in 24h)
    if window_24h > target * 1.5:
        alerts.append({"severity": "warning", "window": "24h", "burn_rate": window_24h / target})
    
    return alerts
```
