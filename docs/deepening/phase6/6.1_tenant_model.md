## 核心组件

### 1. 租户数据模型 (`quant/tenant/models.py`)

```python
class Tenant:
    """租户实体."""
    id: str                    # UUID
    name: str                  # 唯一名称
    display_name: str          # 显示名称
    description: str           # 描述
    status: TenantStatus       # ACTIVE/SUSPENDED/ARCHIVED/PROVISIONING/DEPROVISIONING
    owner_id: str              # 所有者
    admin_ids: List[str]       # 管理员
    member_ids: List[str]      # 成员
    quotas: Dict[ResourceType, ResourceQuota]  # 资源配额
    usages: Dict[ResourceType, ResourceUsage]  # 资源使用量
    namespace_prefix: str      # 命名空间前缀
    labels: Dict[str, str]     # 标签
    annotations: Dict[str, str] # 注解
```

**核心方法:**
- `check_quota(resource_type, requested)` - 检查配额，返回 (bool, message)
- `record_usage(resource_type, usage)` - 记录使用量
- `can_access(user_id)` / `is_admin(user_id)` - 权限检查
- `to_dict()` - 序列化

### 5. 配额管理与告警 (`quant/tenant/quota.py`)

```python
class QuotaManager:
    def check_tenant_quota(self, tenant_id: str) -> Dict[str, dict]:
        """检查单租户配额，返回告警列表."""
    
    def check_all_quotas(self) -> Dict[str, List[dict]]:
        """检查所有租户配额."""
    
    def record_usage(self, tenant_id: str, resource_type: ResourceType, usage: float):
        """记录资源使用量."""
    
    def check_and_alert(self, tenant_id: str) -> List[dict]:
        """检查并触发告警."""
    
    def start_monitoring(self, interval: int = 30):
        """启动配额监控后台任务."""
```

**告警类型:**
- `QUOTA_EXCEEDED` - 硬限制超限 (critical)
- `QUOTA_WARNING` - 超过软限制 (warning)
- `QUOTA_HIGH_USAGE` - 使用率 > 80% (warning)
