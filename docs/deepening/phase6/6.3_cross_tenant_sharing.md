# Phase 6.3 完成归档 — 跨租户数据共享

## 变更摘要
实现跨租户受控数据共享机制，支持细粒度权限控制、数据脱敏、审计日志、行级过滤。

## 核心组件

### 1. 共享权限模型 (`quant/tenant/sharing.py`)

```python
class SharePermission(Enum):
    READ = "read"           # 只读
    WRITE = "write"         # 读写
    ADMIN = "admin"         # 管理权限

class ShareStatus(Enum):
    PENDING = "pending"      # 待审批
    ACTIVE = "active"        # 生效中
    REVOKED = "revoked"      # 已撤销
    EXPIRED = "expired"      # 已过期

@dataclass
class ShareRule:
    share_id: str
    source_tenant_id: str
    target_tenant_id: str
    tables: List[str]                    # 共享的表
    columns: Optional[List[str]] = None  # 共享的列（None=全部）
    permission: SharePermission = SharePermission.READ
    status: ShareStatus = ShareStatus.PENDING
    expires_at: Optional[datetime] = None
    created_at: datetime = field(default_factory=datetime.utcnow)
    created_by: str = ""
    approved_at: Optional[datetime] = None
    approved_by: str = ""
    filters: Dict[str, Any] = field(default_factory=dict)  # 行级过滤条件
    masking_rules: Dict[str, str] = field(default_factory=dict)  # 脱敏规则
```

### 2. 数据共享管理器 (`DataSharingManager`)

```python
class DataSharingManager:
    def request_share(
        self,
        source_tenant_id: str,
        target_tenant_id: str,
        tables: List[str],
        permission: SharePermission = SharePermission.READ,
        columns: Optional[List[str]] = None,
        filters: Optional[Dict[str, Any]] = None,
        masking_rules: Optional[Dict[str, str]] = None,
        expires_at: Optional[datetime] = None,
        requester_id: str = "",
    ) -> str:
        """请求数据共享."""

    def approve_share(self, share_id: str, approver_id: str) -> bool:
        """批准共享请求."""

    def revoke_share(self, share_id: str, revoker_id: str, reason: str = "") -> bool:
        """撤销共享."""

    def get_share(self, share_id: str) -> Optional[ShareRule]:
        """获取共享规则."""

    def list_shares(
        self,
        source_tenant_id: Optional[str] = None,
        target_tenant_id: Optional[str] = None,
        status: Optional[ShareStatus] = None,
    ) -> List[ShareRule]:
        """列出共享规则."""

    def apply_masking(self, share_id: str, row: Dict[str, Any]) -> Dict[str, Any]:
        """应用脱敏规则."""

    def filter_row(self, share_id: str, row: Dict[str, Any]) -> Optional[Dict[str, Any]]:
        """应用行级过滤和脱敏."""
```

### 3. 核心特性

| 特性 | 实现 |
|------|------|
| 权限级别 | READ/WRITE/ADMIN 三级 |
| 生命周期 | PENDING → ACTIVE → REVOKED/EXPIRED |
| 列级控制 | 可选共享特定列 |
| 行级过滤 | 支持 eq/neq/gt/gte/lt/lte/in/contains |
| 数据脱敏 | 内置 5 种脱敏函数 + 自定义扩展 |
| 审计日志 | 完整操作记录（请求/批准/撤销/访问） |
| 过期自动失效 | 支持 expires_at 自动过期 |

### 4. 脱敏函数库

```python
_masking_functions = {
    "mask_id": lambda x: f"{str(x)[:3]}***{str(x)[-3:]}",
    "mask_phone": lambda x: f"{str(x)[:3]}****{str(x)[-4:]}",
    "mask_email": lambda x: f"{x.split('@')[0][:2]}***@{x.split('@')[1]}",
    "mask_name": lambda x: f"{x[0]}**",
    "hash": lambda x: hashlib.sha256(str(x).encode()).hexdigest()[:8],
}
```
