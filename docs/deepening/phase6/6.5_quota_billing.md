## 核心组件

### 1. 配额管理器 (`quant/tenant/quota.py`)

```python
class QuotaManager:
    """配额管理器 - 监控、告警、执行."""

    def check_tenant_quota(self, tenant_id: str) -> Dict[str, dict]:
        """检查单租户配额，返回告警列表."""

    def check_all_quotas(self) -> Dict[str, List[dict]]:
        """检查所有租户配额."""

    def record_usage(self, tenant_id: str, resource_type: ResourceType, usage: float):
        """记录资源使用量."""

    def check_and_alert(self, tenant_id: str) -> List[dict]:
        """检查并触发告警."""

    def start_monitoring(self, interval: int = 30):
        """启动配额监控后台任务."""
```

### 2. 配额告警类型

| 告警类型 | 触发条件 | 严重级别 | 说明 |
|----------|----------|----------|------|
| `QUOTA_EXCEEDED` | 使用量 > 硬限制 | critical | 立即阻止新请求 |
| `QUOTA_WARNING` | 使用量 > 软限制 | warning | 触发告警，不阻塞 |
| `QUOTA_HIGH_USAGE` | 使用率 > 80% | warning | 预警，预留缓冲 |

### 5. 后台监控

```python
# 启动监控
quota_manager = get_quota_manager()
quota_manager.start_monitoring(interval=30)  # 每30秒检查一次

# 注册告警处理器
def my_alert_handler(alert: dict):
    # 发送到 Slack/钉钉/企业微信/Email
    send_alert(alert)

quota_manager.register_alert_handler(my_alert_handler)

# 查询告警历史
alerts = quota_manager.get_alert_history(tenant_id="tenant_001", hours=24)
```
