# Phase 7.3 完成归档 — 自动化响应动作

## 变更摘要
实现熔断器触发时的自动化响应动作：降仓/停止开仓/强平/告警/降级/熔断，响应时间 < 100ms，支持干预/审批/自动执行。

---

## 核心组件

### 1. 响应动作类型

| 动作类型 | 说明 |
|----------|------|
| `REDUCE_POSITION` | 降仓 |
| `STOP_OPENING` | 停止开仓 |
| `FORCE_CLOSE` | 强平 |
| `ALERT` | 告警 |
| `DEGRADE` | 降级 |
| `CIRCUIT_BREAK` | 熔断 |

### 2. 自动化响应引擎 (`AutoResponseEngine`)

核心功能：
- 根据触发条件注册响应动作
- 支持需要审批和自动执行两种模式
- 完整的动作审计日志
- 支持人工审批流程

### 3. 默认动作处理器

| 动作类型 | 处理器 | 功能 |
|----------|--------|------|
| `REDUCE_POSITION` | `_handle_reduce_position` | 降仓（支持策略/品种） |
| `STOP_OPENING` | `_handle_stop_opening` | 停止开仓（策略/品种/账户/全市场） |
| `FORCE_CLOSE` | `_handle_force_close` | 强平（支持全仓/单品种） |
| `ALERT` | `_handle_alert` | 发送告警通知 |
| `DEGRADE` | `_handle_degrade` | 降级（降低频率/杠杆/切换保守模式） |
| `CIRCUIT_BREAK` | `_handle_circuit_break` | 触发熔断 |

---

## 核心功能

### 1. 触发-响应映射
```python
engine.register_action("circuit_break:account_main",
    ResponseAction(
        action_type=ActionType.STOP_OPENING,
        severity=ActionSeverity.CRITICAL,
        target="account",
        target_id="main_account",
        reason="Account circuit breaker triggered",
        params={}
    ))
```

### 2. 熔断触发 -> 自动响应链
- 账户熔断 -> 停止开仓 + 强平
- 策略熔断 -> 停止该策略信号
- 品种熔断 -> 禁止该品种开仓
- 全市场熔断 -> 全市场停止开仓 + 强平风险仓位

### 3. 审批流程
- 支持 `requires_approval` 标记
- 待审批动作进入待审批队列
- `approve_action` / `reject_action` 审批接口
