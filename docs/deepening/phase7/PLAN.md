# Phase 7: 实时风控/熔断增强 — 深化执行计划

## 总体策略
在现有 `RiskManager` (quant/execution/stop_loss.py) 基础上，构建生产级实时风控系统：
- 熔断器模式：多级别熔断 (账户/策略/品种/全市场)
- 实时监控：毫秒级延迟的风险指标计算
- 多维度风控：持仓/资金/流动性/相关性/集中度/杠杆
- 自动化响应：降仓/停止开仓/强平/告警/降级
- 可观测性：实时风控仪表盘、历史回溯、回放复盘
