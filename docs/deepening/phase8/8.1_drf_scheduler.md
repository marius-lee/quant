### 1. DRF 算法核心 (`DRFScheduler`)

```python
class DRFScheduler:
    """DRF (Dominant Resource Fairness) 调度器核心算法.

    DRF 核心思想:
    1. 每个租户有多维资源需求 (CPU, Memory, GPU, IO...)
    2. 计算每个租户的主导资源份额 = max(需求_i / 总资源_i)
    3. 优先调度主导份额最小的租户
    4. 支持加权 DRF: 份额 / 权重
    """

    def submit_task(self, tenant_id: str, task: Task) -> int:
        """提交任务到租户队列，计算加权主导份额."""
        dominant = task.dominant_share(self._cluster_resources)
        weight = self.get_tenant_weight(tenant_id)
        weighted_share = dominant / weight
        heapq.heappush(self._tenant_queues[tenant_id], (weighted_share, self._seq, task))

    def pop_next_task(self, max_per_tenant: Dict[str, int]) -> Optional[Tuple[str, Task]]:
```

### 2. 优先级继承 (`PriorityInheritanceManager`)

```python
class PriorityInheritanceManager:
    """解决优先级反转问题.

    当高优先级任务等待低优先级任务持有的资源时，
    临时提升持有者优先级至等待者优先级，防止中优先级任务抢占。
    """

    def acquire(self, task_id: str, resource: str, priority: int) -> bool:
        """尝试获取资源，失败则记录等待者并提升持有者优先级."""

    def release(self, task_id: str, resource: str) -> List[str]:
        """释放资源，唤醒等待者，恢复原持有者优先级."""
```

### 3. 抢占管理 (`PreemptionManager`)

```python
class PreemptionManager:
    """低优先级任务抢占，支持检查点保存与恢复."""

    def try_preempt(self, high_priority_task: Task, tenant_quotas: Dict) -> List[Task]:
        """为高优先级任务抢占资源:
        1. 按优先级从低到高排序运行中任务
        2. 跳过同租户任务
        3. 保存检查点
        4. 释放资源直到满足需求
        """
```

### 4. 调度器整合 (`Scheduler`)

```python
class Scheduler:
    """租户感知任务调度器 - 整合 DRF、优先级继承、抢占."""

    def submit(self, task: Task) -> str:
        """提交任务，自动计算资源需求，入 DRF 队列."""

    def _worker_loop(self, worker_id: int):
        """工作线程循环:
        1. 从 DRF 弹出任务
        2. 尝试获取资源锁 (优先级继承)
        3. 执行回调
        4. 释放资源，处理重试
        """
```

## 关键特性

| 特性 | 实现 |
|------|------|
| **多资源公平** | DRF 算法，支持 CPU/Memory/GPU/IO/Network 5 维 |
| **加权公平** | 租户权重 `weight`，份额 / 权重 |
| **租户配额** | `max_concurrent_tasks`、`max_cpu_cores`、`max_memory_mb` |
| **优先级继承** | 解决优先级反转，资源锁自动提升持有者优先级 |
| **抢占** | 低优先级任务检查点保存后释放资源 |
| **资源需求声明** | `Task.resource_demand: Dict[ResourceType, float]` |
| **并发控制** | 租户级 `max_concurrent_tasks` + 保留槽位 |
| **检查点回调** | `PreemptionManager.set_checkpoint_callback` |
