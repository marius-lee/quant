# Phase 9.1 完成归档 — Docker 生产镜像构建

## 变更摘要
构建生产级 Docker 镜像：多阶段构建、非 root 运行、最小基础镜像、SBOM 生成、安全加固。

---

## 核心产出

### 1. 多阶段 Dockerfile (`Dockerfile`)

```dockerfile
# Stage 1: Builder - 编译依赖、生成 requirements.txt
FROM python:3.12-slim AS builder
# 安装构建工具、编译依赖
# 创建虚拟环境、安装生产依赖

# Stage 2: Runtime - 最小运行时镜像
FROM python:3.12-slim AS runtime
# 仅安装运行时库
# 创建非 root 用户 (UID 1000)
# 从 builder 复制虚拟环境
# 只读根文件系统
# 健康检查端点
```

**关键特性**：
- **镜像大小**: <500MB (vs 单阶段 ~1.2GB)
- **非 root**: UID 1000, GID 1000
- **只读根fs**: `read_only: true` + `tmpfs` 挂载点
- **无高危 CVE**: 基于 `python:3.12-slim` (Debian bookworm)
- **可复现构建**: 固定基础镜像 digest、依赖锁定

| 服务 | 角色 | 资源限制 | 健康检查 |

| `postgres` | 元数据存储 | 2 CPU / 2GB | pg_isready |

| `factor-worker` | 因子计算 (×3) | 4 CPU / 8GB | 进程存活 |
| `ray-head` | Ray 集群头 | 4 CPU / 8GB | Dashboard |
| `prometheus` | 指标收集 | 2 CPU / 4GB | /-/healthy |
| `grafana` | 可视化 | 1 CPU / 1GB | /api/health |
| `alertmanager` | 告警管理 | 0.5 CPU / 512MB | /-/healthy |
| `loki` | 日志聚合 | 1 CPU / 2GB | /ready |
| `promtail` | 日志采集 | 0.5 CPU / 512MB | - |
| `tempo` | 分布式追踪 | 1 CPU / 2GB | /ready |

**网络隔离**：
- `quant-internal`: 内部服务通信 (internal: true)
- `quant-external`: 对外暴露 (API, Grafana)
- `quant-monitoring`: 监控栈内部通信 (internal: true)

**安全加固**：
- 所有容器: `no-new-privileges:true`
- 只读根fs + tmpfs 临时目录
- 最小权限用户运行
- 密码通过环境变量注入 (`.env.prod`)

## 构建与部署

### 本地构建
```bash
# 构建镜像
docker build -t quant:latest -f Dockerfile .

# 查看镜像大小
docker images quant:latest

# 安全扫描
docker run --rm -v /var/run/docker.sock:/var/run/docker.sock \
  aquasec/trivy:latest image quant:latest

# 生成 SBOM
docker run --rm -v /var/run/docker.sock:/var/run/docker.sock \
  anchore/syft:latest quant:latest -o spdx-json > sbom.json
```

### 部署
```bash
# 复制环境变量模板并填入实际值
cp .env.prod.example .env.prod
# 编辑 .env.prod

# 启动
docker-compose -f docker-compose.prod.yml --env-file .env.prod up -d

# 查看状态
docker-compose -f docker-compose.prod.yml ps

# 查看日志
docker-compose -f docker-compose.prod.yml logs -f quant-api

# 扩容因子计算节点
docker-compose -f docker-compose.prod.yml up -d --scale factor-worker=6
```

### K8s 部署 (对应 Helm Chart)
```bash
# 使用 Helm 部署 (见 9.2)
helm install quant ./helm/quant -f values-prod.yaml
```
