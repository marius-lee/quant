# Phase 9.2 完成归档 — K8s Helm Chart 编排

## 变更摘要
构建完整的 Kubernetes Helm Chart：所有微服务 Chart、依赖管理、多环境 Values 差异化、网络策略、自动伸缩、RBAC。

---

## 核心产出

### 1. Helm Chart 结构 (`helm/quant/`)

```
helm/quant/
├── Chart.yaml                 # Chart 元数据、依赖声明
├── values/
│   ├── values.yaml           # 默认配置
│   ├── values-dev.yaml       # 开发环境
│   └── values-prod.yaml      # 生产环境
└── templates/
    ├── _helpers.tpl          # 模板函数
    ├── quant-api-deployment.yaml
    ├── configmap.yaml
    ├── secrets.yaml
    ├── networkpolicies.yaml
    ├── ingress.yaml
    ├── hpa.yaml
    └── rbac.yaml
```

### 2. 依赖管理 (`Chart.yaml`)

```yaml
dependencies:
  - name: postgresql
    version: "12.x.x"
    repository: "https://charts.bitnami.com/bitnami"
    condition: postgresql.enabled
  - name: redis
    version: "17.x.x"
    repository: "https://charts.bitnami.com/bitnami"
    condition: redis.enabled
  - name: minio
    version: "11.x.x"
    repository: "https://charts.bitnami.com/bitnami"
    condition: minio.enabled
  - name: prometheus
    version: "15.x.x"
    repository: "https://prometheus-community.github.io/helm-charts"
    condition: prometheus.enabled
  - name: grafana
    version: "6.x.x"
    repository: "https://grafana.github.io/helm-charts"
    condition: grafana.enabled
  - name: loki
    version: "5.x.x"
    repository: "https://grafana.github.io/helm-charts"
    condition: loki.enabled
  - name: tempo
    version: "1.x.x"
    repository: "https://grafana.github.io/helm-charts"
    condition: tempo.enabled
```

**特性**：
- 所有依赖服务可通过 `condition` 开关控制
- 使用 Bitnami 官方 Chart，维护良好
- 监控栈使用 Prometheus/Grafana 社区 Chart

### 3. 多环境配置 (`values/*.yaml`)

| 环境 | 副本数 | CPU/内存 | 自动伸缩 | 网络策略 | 高可用 |
|------|--------|----------|----------|----------|--------|
| Dev | 1 | 1C/1G | 关闭 | 关闭 | 单节点 |
| Staging | 2 | 2C/2G | 开启 | 开启 | 双节点 |
| Prod | 3+ | 4C/4G | 开启 (HPA) | 开启 (严格) | 多节点/集群模式 |

**关键差异**：
```yaml
# Dev
quant.replicaCount: 1
networkPolicy.enabled: false
postgresql.persistence.size: 10Gi

# Prod
quant.replicaCount: 3
quant.autoscaling.enabled: true
networkPolicy.enabled: true
postgresql.replication.enabled: true
redis.cluster.enabled: true
minio.mode: distributed
```

### 4. 核心模板

| 模板 | 功能 |
|------|------|
| `quant-api-deployment.yaml` | API 部署、健康检查、资源限制、反亲和性、拓扑分布 |
| `configmap.yaml` | 应用配置注入 |
| `secrets.yaml` | 敏感配置 (API Keys、密钥) |
| `networkpolicies.yaml` | 默认拒绝、服务间通信、监控抓取、DNS 解析 |
| `ingress.yaml` | TLS 终止、速率限制、多域名路由 |
| `hpa.yaml` | CPU/内存双指标伸缩、冷却窗口、策略 |
| `rbac.yaml` | ServiceAccount、Role/RoleBinding、ClusterRole |

### 5. 安全加固模板

```yaml
# _helpers.tpl 中的安全上下文
quant.podSecurityContext:
  runAsNonRoot: true
  runAsUser: 1000
  runAsGroup: 1000
  fsGroup: 1000

    type: RuntimeDefault

```

### 6. 网络策略

| 策略 | 方向 | 来源/目标 | 端口 |
|------|------|-----------|------|
| `deny-all` | Ingress/Egress | 默认拒绝 | - |
| `api-ingress` | Ingress | ingress-nginx namespace | 8521 |
| `internal` | Ingress/Egress | 同 namespace | 所有 |
| `monitoring` | Ingress | monitoring namespace | 9090 |
| `egress-dns` | Egress | kube-system | 53 UDP/TCP |

## 部署使用

### 安装依赖
```bash
cd helm/quant
helm dependency update
```

### 开发环境部署
```bash
helm install quant-dev ./quant \
  -f values/values-dev.yaml \
  --namespace quant-dev \
  --create-namespace
```

### 生产环境部署
```bash
# 创建密钥
kubectl create secret generic quant-secrets \
  --from-literal=TUSHARE_TOKEN=xxx \
  --from-literal=JWT_SECRET_KEY=xxx \
  --namespace quant-prod

# 部署
helm install quant ./quant \
  -f values/values-prod.yaml \
  --namespace quant-prod \
  --create-namespace \
  --wait --timeout 10m
```

### 升级
```bash
helm upgrade quant ./quant \
  -f values/values-prod.yaml \
  --namespace quant-prod \
  --wait --timeout 10m
```

### 回滚
```bash
helm rollback quant <revision> -n quant-prod
```

### 验证
```bash
# 检查所有 Pod 就绪
kubectl get pods -n quant-prod -w

# 检查服务
kubectl get svc -n quant-prod

# 检查 Ingress
kubectl get ingress -n quant-prod

# 检查 HPA
kubectl get hpa -n quant-prod
```
